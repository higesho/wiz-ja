# Wizardry 6 日本語訳ガイド（翻訳作業者向け）

ユーザー所有のゲームを個人的に日本語化するための作業。訳文はローカルの翻訳ファイルにだけ書き、外部へ出さない。

## 入出力

- 原文: `trans/msg_en.txt` — 1 行 = `ID<TAB>英文`。制御文字・非表示文字は `\xNN` 表記、バックスラッシュも `\x5c`
- 訳文: `ID<TAB>s<TAB>訳文` の形で 1 行ずつ書く（2 列目は常に `s`）。原文と同じ ID をすべて、同じ順に出力する
- 訳さない行（記号だけの行、空行、`\x..` だけの行、意味のない内部名など）は、原文をそのまま 3 列目に入れる

## 表示の仕組み（制約の理由）

- 画面は 8×8 ドットのマス目。日本語 1 文字 = 1 マス（美咲フォント）、英数字・記号 1 文字 = 1 マス
- 日本語 1 文字はデータ上 2 バイト、英数字は 1 バイト
- 迷宮のメッセージ窓は横 40 マス × 縦 5 行。原文の 1 行（1 ID）が画面の 1 行になる場面が多い（中央揃え）
- 会話（NPC）は ID の文章が続けて流し込まれ、スペースで折り返される

## 必ず守るルール

1. **行頭の制御文字はそのまま残す**: 行頭にある英数字以外の記号の並び（`^` `%` `@` `!` `$` `"` `*` `(` `~` `]` `` ` `` `_` `{` など）と `\xNN` は、原文と同じ順で行頭に置く。例: 原文 `%]WHO...` → 訳文 `%]だれだ…`
2. **行中の特殊記号**: 行の途中の `^` `$` `` ` `` `}` `{` `~` `\xNN` は意味を持つことがある（名前の差し込みなど）。位置関係を保って残す
3. **長さ**:
   - 訳文の表示幅（日本語 1 文字 = 1、英数字 1 文字 = 1）は **原文の文字数以下**
   - バイト数（日本語 2、英数字 1）は **78 以下**。さらに原文が 16 文字以下の行は **max(原文文字数+4, 12) バイト以下**（例: 原文 7 文字 → 日本語 5 文字まで、原文 3 文字 → 日本語 6 文字まで）
   - 迷宮のメッセージ（原文が 38 文字前後の行が続くもの）は 1 行 38 マス以内
4. **1 ID = 1 行の対応を崩さない**。文章の流れが自然になるよう、同じまとまり（連続した ID）の中で内容を前後の行に振り分けてよい。ただし各行は単独でも画面の 1 行として読めるように区切る
5. **小文字の行**（`add_member` のような、`_` を空白に使う行）は画面上の見出し・ボタン。`_` は桁合わせの空白なので、語の開始桁を原文とそろえ、余った分は `_` で埋める。`}` は「？」の意味なので「？」に置き換えてよい
6. 文字種: 漢字かな交じり。使える文字は JIS 第一・第二水準の漢字、ひらがな、カタカナ、全角記号（「」、。・…！？ー〜（）など）。半角カナや絵文字は使わない。数字・英字は半角のまま（例: 名前の差し込み、数値）
7. 文体: 地の文は「〜だ／〜である」調の簡潔な文。NPC のセリフは人物像に合わせる（海賊はべらんめえ調、王族は尊大、など）。メニューは体言止めか短い命令形
8. ウィザードリィの日本語版で定着した用語を使う（用語集 `trans/glossary.tsv` を必ず参照し、そこにある語はその訳語に統一）

## 出力前の自己チェック

- ID の数と順序が原文と一致しているか
- 行頭の制御文字が残っているか
- 長さ制限を超えていないか


## 物語・会話の本文（ID 8000 以降）の追加ルール

訳す前に `trans/parts/en_sNN.txt` を最後まで通読し、どの場面か・誰が話しているかをつかむこと。

### 表示のしくみ
- **迷宮のメッセージ**（行頭が `^` `$` の行、または行頭に記号がない連続した ID の行）: 1 ID = 画面の 1 行。5 行で 1 ページ（原文と同じ行数に収める）。
  - 行頭に記号がない行は、その行だけで **中央揃え**（桁 = 20 − (表示幅+1)/2）。
  - 行頭 `^` の行は、直前の行の開始桁にそろえて左詰めで出る。`$` の行は左端（0 桁目）から出る。
  - したがって「1 行目が短い → 開始桁が右へずれる → 続く `^` 行が右端（40 桁）からはみ出す」ことがある。検査スクリプトが `overflow` として知らせるので、1 行目を長めにするか、`^` 行を短くすること。
- **NPC の会話**（行頭が `%` `!` `@` `"` など）: 連続する ID の文を 1 本の文章として流し込み、**半角スペースの位置で折り返す**。日本語は語の区切りがないので、文節の切れ目に半角スペースを 1 つ入れる（スペース 1 つ = 1 桁）。スペースなしで 30 桁を超える塊は折り返せないのでエラーになる。
- 1 つの話のまとまり（連続 ID）の中で、文を前後の ID に振り分けてよい。ただし ID の数と順序は変えない。1 つの ID が空になる場合は、原文と同じく空にせず、短い言葉（「……」など）で埋める。

### 訳さない行
- 会話のキーワード表（プレイヤーが英単語で入力する言葉と照合するもの）は、あらかじめ抜いてあり、渡されない。`en_sNN.txt` に残っている行はすべて訳す。
- 迷ったら、原文の意味を保った自然な文にする。固有名詞（人名・地名・店名）は `trans/scen_ja.txt`（モンスター・NPC・アイテム名の既訳）を `grep` で引いて、同じ表記にそろえる。

### 用語メモ
- 新しく決めた固有名詞や用語は、担当ごとの `trans/parts/terms_sNN.tsv`（`英語<TAB>日本語`）に書き出す。後で全担当分を突き合わせて統一する。

### 文体
- 地の文: 「〜だ。」「〜である。」調の簡潔な文。
- 登場人物のセリフ: 話者に合わせる（海賊=荒っぽい口調、老人=古風、王族=尊大、妖精=軽い、など）。原文の方言・なまりの雰囲気を日本語らしく置き換える。
- 原文の下品な冗談・駄洒落は、意味が通る範囲で日本語の言葉遊びに置き換えるか、素直に訳す。

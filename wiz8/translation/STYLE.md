# ウィザードリィ8 日本語化 翻訳ルール

翻訳担当者(人・AI)はチャンクを訳す前に必ずこのファイルを読むこと。
用語は `glossary.tsv`、人物ごとの話し方は `voices.json` が正本。
各チャンクファイルの `terms`(そのチャンクに出てくる用語)と `voice`(話し手の口調)はここから自動で抜き出したもの。

## 1. 作業の流れ
1. `work/chunks/<チャンク名>.json` を読む。
2. `lines` の各要素の `en` を日本語に訳す。
3. `work/ja/<チャンク名>.json` に次の形で書き出す(UTF-8、JSONオブジェクト)。
   ```json
   {
     "NPC SCRIPTS/NPC_ANNA.NSF@1b": "訳文",
     "NPC SCRIPTS/NPC_ANNA.NSF@267": "訳文",
     "_notes": ["用語表にない固有名詞 Foo を「フー」と訳した", "..."]
   }
   ```
   - `lines` の id をすべて、1つも欠かさずに含める。id は一字一句そのまま。
   - `_notes` は任意。用語表にない固有名詞を新たに訳したとき、意味が取れず自信がないときに書く。

## 2. 絶対に守ること(壊れるとゲームが落ちる・表示が崩れる)
- **書式指定子** `%s` `%d` `%ld` `%hs` `%c` `%%` などは、**個数も順番も原文と同じ**にする。語順の都合で入れ替えてはいけない。
- 改行 `\n` は原文と同じ位置・同じ数を保つ(端末画面やリスト表示で使われる)。
- 先頭・末尾の空白は原文どおり残す(文字列を連結して表示するため)。
- 英字の略号・コード(`HLL`、`IUF`、`EWAXX`、`RFS-81`、座標や数値)はそのまま。
- 端末に入力するログイン名・パスワード(`MATILDA` `HPIOU1` `EGGLES` `VAUGHN` など、大文字だけの1語の行)は英字のまま。プレイヤーがそのまま入力するため。
- 文の断片はそのまま断片として訳す。UI文字列の多くは「名前 + 断片」で連結表示される。
  - 例: `is drained` → `は衰弱した`、`becomes charmed!` → `は魅了された!`、`as well as ` → `および `。
  - 例: `'s guardian angel prevents %d damage!` → `の守護天使が%dのダメージを防いだ!`。

## 3. 表記
- 句読点は全角「、」「。」。感嘆符・疑問符は「!」「?」(半角でも全角でもよい。取り込み時に全角へ統一する)。
- 三点リーダーは「……」(… を2つ)。原文の「...」「. . .」も同じ。
- ダッシュ(`--` や `—`)は「――」。
- 台詞中の引用 "..." は「」、引用の中の引用は『』。
- 強調の `*word*` はアスタリスクごと残す(例: `*chosen*` → `*選ばれし*`)。`-word-` も同様。
- 原文がすべて大文字の叫び(`GET OUT!`)は、語調を強めた日本語にする(「出て行け!!」)。英字のままにしない。
- 数字は半角。半角カタカナは使わない。
- ルビ・括弧での英語併記はしない。

## 4. 用語
- `terms` に載っている語は必ずその訳を使う。複数形・所有格(Rapax's、Trynnies)も同じ訳にする。
  - ただし能力値・呪文系統・状態などの一般語(Experience、Speed、Fire、Dead など)は、ゲーム用語として使われているときだけ用語表に従う。ことわざや普通の文の中ではふつうに訳してよい。
- 用語表にない固有名詞(人名・地名・品名)はカタカナで音訳し、`_notes` に「英語 → 訳」を書く。
- 秘宝・神話の用語は意味より用語表を優先する(Ascension は「昇神」。「昇天」とは書かない)。
- 会話のキーワード(地名や人名)を台詞で言及するときも用語表どおりにする。
- 階級・敬称は名前の後ろに付ける(Sgt. Glumph → グルンフ軍曹、General Yamir → ヤミール将軍)。

## 5. 訳し方
- 意味を省いたり付け足したりしない。冗談や皮肉は日本語として通じる形に意訳してよい。
- 原文の文の数と流れはおおむね保つが、日本語として自然な語順にする。
- 話し手の口調は `voice` に従う。一人称・二人称・語尾を1つのチャンク内で揺らさない。
- パーティ(プレイヤー一行)への呼びかけは、指定がなければ「あなたたち」(丁寧な人物)か「お前たち」(乱暴な人物)。
- 罵り言葉は日本語の自然な罵倒に(damn→「くそっ」、hell→「ちくしょう」など)。
- アイテム名・呪文名・モンスター名など(`dbs_` チャンク)は短く:
  - 武器・防具の種類名はカタカナ(Longsword→ロングソード、Main Gauche→マンゴーシュ)。修飾語は日本語(Poison Dagger→毒のダガー)。
  - 呪文名は漢字中心の短い意訳(Fireball→火球、Heal Wounds→傷の治癒、Bless→祝福)。
  - データの領域に上限がある:モンスター名・呪文名・NPC名・マップ名は23文字以内、アイテム名は29文字以内。上限内なら原文より長くてよい(無理に略さない)。
- UIのボタン・見出しは短く(「Load」→「ロード」、「Options」→「オプション」)。キー名 `(ENTER)` `(ESC)` などはそのまま。
- 開発用テストNPC(Play Day など)の台詞も普通に訳す。
